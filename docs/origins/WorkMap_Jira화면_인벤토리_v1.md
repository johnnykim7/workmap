# WorkMap — Jira 화면 인벤토리 (UX/UI 누락 방지 자산)

> 문서 상태: 자산화 1단계 — **화면 목록 고정**
> 작성일: 2026-06-23
> 목적: "Jira처럼" 한마디로 AI가 알아서 채우면 디테일이 대량 누락된다(에픽 화면에서 "연결된 업무 항목"·"Confluence 콘텐츠" 누락이 그 증거).
> **운영 방식(확정 2026-06-23): 기준은 기획서 v0.4. 목업은 참고/검토용일 뿐 비교 대상 아님.** 추후 사용자가 Jira 화면을 캡처해 주면 그때그때 요소를 분해해 **기획서 §9.x를 직접 보완**한다. 이 문서는 "어떤 화면을 아직 안 봤나"를 가볍게 추적하는 체크리스트일 뿐, 목업과의 diff를 관리하지 않는다.
> 정본 기획서: `WorkMap_제품기획서_v0.4_Jira기반.md`

## 운영 방식 (3단계)

1. **목록 고정**(이 문서 §A) — Jira 핵심 화면이 무엇인지 먼저 합의·고정.
2. **캡처 → 분해**(이 문서 §B, 화면마다 추가) — 사용자가 실제 Jira 화면을 캡처해 주면, 화면을 `영역·요소·동작·우리 대응`표로 분해해 박는다.
3. **구현 체크리스트** — 구현 시 분해표의 각 요소를 항목 단위로 체크. "이 요소 구현했나"가 추적됨(CLAUDE.md "완료 선언 전 교차 검증"과 맞물림).

> AI가 기억으로 "알아서" 채우는 게 아니라, **표에 박힌 요소를 옮기는** 작업으로 만든다. 누락이 나도 "표의 N번 요소 빠짐"으로 추적된다.

## B. 화면별 요소 분해표 (캡처 들어올 때마다 추가)

> 형식: 화면당 한 절. `영역 → 요소 → 동작 → 우리 대응(기획서 위치/구현 메모)`.

### B.1 에픽 상세 (#1) — 분해 (2026-06-23 캡처 기준)

> 캡처: 반품구조대 / 목록 분할뷰 / ZGOH-5 "테스트 에픽2" 상세.

| 영역 | 요소 | 동작 | 우리 대응 |
|------|------|------|----------|
| 상단 탭 | 요약·목록·보드·백로그·캘린더·타임라인·문서·양식·+ | 뷰 전환, +로 탭 추가 | §9.1 ✅ |
| 상단 우측 | 공유·번개(자동화)·내보내기·전체화면 | | §13.5 자동화 P3 / 내보내기 미명기 ⚠️ |
| 본문 헤더 | key(ZGOH-5)·위/아래 화살표·워치(👁1)·공유·⋯ | 이전/다음 항목 이동, 구독 | §9.3 ✅ |
| 본문 | 에픽 색상칩 + 제목(인라인 편집) | | §9.3 ✅ |
| 본문 | `+` 액션메뉴 · ⋯ · 상태(할일▾) · 코드(</>)· 자동화 · **업무 유형 전환** | 유형 변경 등 | §13.1 유형전환(방금 추가) ✅ |
| 본문 | 설명 (편집) | 리치 에디터 | §9.4 ✅ |
| 본문 | **하위 업무 항목** + 진행률 바(0% 완료) + ⋯·컬럼·+ | 하위 표, 행 인라인(우선순위·담당자·상태) | §9.3 ✅ |
| 본문 | **연결된 업무 항목** (별도 섹션) | 링크 추가(blocks/relates) | §13.1 링크는 있으나 **상세화면 위치 미명기** ⚠️ |
| 본문 | **Confluence 콘텐츠** (외부 문서 임베드) | 템플릿/문서 연결 | **임베드 슬롯 개념 누락** ⚠️ (우리는 자체 문서탭 연결로) |
| 우측 패널 | 세부 사항(⚙ 구성) | 접이식 | §9.3 ✅ |
| 우측 패널 | 담당자(+나에게 할당)·레이블·상위 항목·Team·기한·시작 날짜·Sprint·Story point estimate·보고자 | 인라인 수정 | §9.3 ✅ (Story point**estimate** 용어차) |

**이 화면이 드러낸 누락/확인필요:**
1. ⚠️ **연결된 업무 항목** 섹션 — 상세 본문에 하위(부모자식)와 **별개**로 존재. §9.3 Epic 구조도에 명기 필요.
2. ⚠️ **외부 문서 임베드 슬롯** (Confluence 자리) — 항목 본문에서 관련 문서 끌어 거는 슬롯. 우리는 자체 §13.5 문서탭/외부링크로. §9.3 + §13.7.3 반영 필요.
3. ⚠️ **내보내기(Export)** — 상단 우측 버튼. 기획서 미명기(보고/목록 내보내기). 경미하나 기록.
4. 용어: **Story point estimate** (Jira 표기) ↔ 우리 "스토리포인트"(§8.2). 통일 여부 결정.
