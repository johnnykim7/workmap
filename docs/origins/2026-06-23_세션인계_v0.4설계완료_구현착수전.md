## 1. 이번 세션에 한 일 (전부 CR-006)

ClickUp(v0.3) → Jira 애자일(v0.4) 전환. 기존 v0.3 설계를 **전면 재작성**.

### 1-1. T1~T3 전면 개정 (14개 문서)
- **work_item 단일 테이블**: Epic/Story/Task/Bug/Sub-task를 `issue_type` + `parent_id`/`epic_id`로. 별도 테이블 금지(BIZ-106). 유형별 필드는 단일 테이블 + 화면 표시 차등(BIZ-102).
- **측정 추상화 Phase 1 포함**: measure_unit 마스터 + work_item.target/current. 개발=정성, 운영=정량 한 모델.
- **관리자 마스터**(하드코딩 금지, BIZ-107): workflow/workflow_status/workflow_transition · measure_unit · field_scheme · issue_type · project_template.
- **모듈 A~I**, 기능 53개(요약표=상세카드 정확히 일치). Phase 1 MVP는 High 표기.

### 1-2. 캡처 보며 추가 보강 (Jira 실화면 대조)
- **ProjectType enum 제거 → project_template 마스터**: "유형은 코드 아닌 데이터". DEV/OPS/PLAN은 시드 예시. 템플릿이 묶는 것 = 탭(default_tabs)+워크플로(default_workflow_id)+업무유형(issue_type_codes)+필드스킴. **템플릿 추가는 DB 직접/Flyway SQL**(전용 화면·API·MCP 안 만듦 — 사용자 결정).
- **프로젝트 생성 = 다단계 마법사** + "샘플 데이터로 시작" 토글(withSample).
- **스크럼/칸반은 생성 시 템플릿이 결정**(보드에서 고르는 게 아님).
- **승인(Approval) 기능 Phase 1**: workflow_status.is_approval 게이트 + approvals 테이블. WMP-OPS-005/006, BIZ-110/111, POL-011. 풀 캐스케이드 완료(T1-3/4/5/6 + T3-1/2/3/5).
- **검색·필터·퀵필터 / 벌크편집 / 유형전환 / 프로젝트 가시성·멤버초대 / 연결된 업무항목** 보강(Jira 누락분).
- **보고서**: 분포위젯 P1, 리드/사이클타임·CFD P2, **배포빈도 제외**(FlowGuard 축).

### 1-3. UI 규칙 (CLAUDE.md FE 아키텍처 + T3-3에 박음 — 구현 시 강제)
1. **ds-ui 필수, 네이티브 UI 절대 금지**(alert/confirm/네이티브 select·checkbox·date·dialog 금지 → ds-ui Dialog/Select/Checkbox/DatePicker/Switch/Toast).
2. **색 절제**: 신호(상태·우선순위·막힘)에만 색, 본문/레이아웃 중립 톤. 목업 톤(slate 베이스+신호색) 유지.
3. **버튼 일관성**: 생성/추가/저장=primary · 수정=secondary · 삭제=destructive · 취소=ghost. 공통 래퍼로 관리.
4. **반복 패턴 일관성**: 경고/정보(Alert/Toast 의미별 색) · 검색(SearchInput) · 빈상태(EmptyState) · 확인삭제(ConfirmDialog) · 폼(Field 래퍼) · 페이징/테이블 공통화.
5. **로딩 = 스켈레톤 필수**(ds-ui Skeleton).
